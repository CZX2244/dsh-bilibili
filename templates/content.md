# B站视频内容总结模板：内容实录式（dsh-bilibili 自定义模板）

目标：忠实还原「视频本身讲了什么」，而不是教用户怎么看视频。
输出 = 视频内容正文（按视频自身结构分段）+ 高赞评论摘录。不写钩子、不写名场面、
不写观看建议、不写转发语——只写视频里实际有的内容。

## 输出结构

1. **标题行**：自拟一行能说明视频内容的标题；下一行附元数据：原标题 / UP主 / 时长 / 数据获取日期（YYYY-MM-DD）。

2. **视频内容正文**：按视频实际讲述顺序分成若干段（通常 3-8 段），每段：
   - **段落小标题**：用视频内容本身的主题命名（如「测试环境说明」「GLM5.3 演示」「DeepSeek 演示」），不用「开场」「高光」「名场面」等观影导向词；
   - **时间戳**：`MM:SS-MM:SS` 仅作段落位置标记；
   - **内容要点**：2-5 条，完整转述这段讲了什么——论点、过程、数据、结论，逐条内嵌时间戳 `(MM:SS)`；关键内容加粗；
   - **配图**（仅当画面承载了文字无法表达的信息，如图表/界面/演示细节时）：帧路径 + (MM:SS)；没有就省略。
   - 视频里出现的数据、名称、步骤、公式等要原样写进正文，不要只写「差距明显」「效果好」这类评价而省略具体内容。

3. **UP主核心结论**：把视频最终想传达的结论完整列出（1-3 条）。

4. **高赞评论摘录**：按点赞数从高到低列出评论区高赞内容（如有样本）：
   - 格式：`[用户名]（N 赞）评论内容`；有回复则一并列出；
   - 标注「评论样本观点，非UP主观点，不代表全体观众」；无法获取时整节省略。

## 禁止出现（除非用户明确要求）

- 开场钩子、值不值得看、适合谁看
- 「高光 / 名场面 / 高潮 / 前方高能」等观影引导
- 观看建议、倍速建议、跳看建议
- 转发分享语
- 信息密度 / 制作水平 / UP主风格等打分

## 标注规范

- ASR 转录引用统一标 [未经人工校对]；精确引用仅限官方字幕或已校对内容。
- 价格/版本/活动等时效信息注明数据获取日期。
- 「多数/共识」必须有样本量，否则写「部分样本显示」。
- 没有可靠证据的字段直接省略，不编造；转录缺失时明确说明「转录未获取」，并注明哪些内容基于弹幕/评论推断。
- 时间戳用 MM:SS。
- 配图只引用「配图建议=适合」且画面清晰的帧；无视觉描述时给帧路径列表即可，不对画面内容做断言。
