# B站视频总结模板：时间轴式（通用）

适用：所有类型的视频。目标 = 用户不点开视频也能完整拿到内容；
结构 = 主标题 + 开场钩子 + 时间轴分段（小标题 + 要点 + 配图）+ 结尾结论。

## 输出结构

1. **主标题**：一行概括视频核心内容的标题（可自拟，比原标题更能说明内容）；
   附视频元数据：原标题 / UP主 / 时长 / 播放与互动数据 / 数据获取日期（YYYY-MM-DD）。

2. **开场钩子**（1 段）：一段话说清视频讲了什么、核心看点是什么、值不值得看。

3. **时间轴分段正文**：按内容时间顺序分成若干段（通常 3-8 段），每段：
   - **小标题**：一句话概括这段内容（风格可生动，如「开场」「高潮名场面」「结论与建议」）；
   - **起始时间戳**：`MM:SS`（或 `MM:SS-MM:SS` 区间）；
   - **要点**：2-4 条，每条内嵌精确时间戳 `(MM:SS)`；关键结论加粗；
   - **配图**（如适用）：标注对应帧图「`路径`（MM:SS）」，模型可用 read_image 查看；
     没有合适的帧就跳过，不硬凑。

4. **结尾结论**（1 段）：总体结论 / 一句话推荐 / 值得跳看的时间点。

## 配图规则

- 优先选用「字幕驱动 + 场景切换」抓到的帧；每个段落至多 1-2 张；
- 无法配图的段落直接省略配图，不虚构；
- 若当前模型无视觉输入能力，改为给出帧路径列表。

## 标注规范

- ASR 转录引用统一标 [未经人工校对]；精确引用仅限官方字幕或已校对内容。
- 价格/版本/活动等时效信息注明获取日期。
- 「多数/共识」必须有样本量，否则写「部分样本显示」。
- 没有可靠证据的字段省略，不编造。
